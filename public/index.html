How the campaign works

  1. Create or join a room. Share the four-character code with your partner. Completed campaigns publish both callsigns to this server's scoreboard; avoid real names if you prefer.
  2. Establish voice contact. Play within speaking distance or use a separate voice call. Voice is not built in.
  3. Navigate together. The host sees the map, barriers, key and exit. The Operator sees only movement controls.
  4. Clear all three stages. Collect each key before its hatch. A timeout fails the entire campaign. Bank unused seconds from every cleared stage: Gold above 60s, Silver above 30s, Bronze for completion.
